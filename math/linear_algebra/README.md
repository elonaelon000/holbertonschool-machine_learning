# Linear Algebra

This project introduces vectors, matrices, tensors, and the basic matrix operations used in machine learning. The exercises begin with plain Python and then use NumPy to perform the same operations more efficiently.

## Learning Objectives

By the end of this project, I should be able to explain and use:

- vectors, matrices, and tensors
- array shapes
- matrix transpose
- element-wise operations
- dot products and matrix multiplication
- axes (`axis=0` and `axis=1`)
- array slicing
- NumPy arrays and broadcasting

## Requirements

- Ubuntu 22.04
- Python 3.10
- NumPy
- All files start with `#!/usr/bin/env python3`
- Code follows `pycodestyle`
- Every module and function has a docstring

## Tasks

### Plain Python

- `0-slice_me_up.py` - list slicing
- `1-trim_me_down.py` - matrix slicing
- `2-size_me_please.py` - matrix shape
- `3-flip_me_over.py` - matrix transpose
- `4-line_up.py` - element-wise array addition
- `5-across_the_planes.py` - element-wise matrix addition
- `6-howdy_partner.py` - array concatenation
- `7-gettin_cozy.py` - matrix concatenation
- `8-ridin_bareback.py` - matrix multiplication

### NumPy

- `9-let_the_butcher_slice_it.py` - NumPy slicing
- `10-ill_use_my_scale.py` - NumPy shape
- `11-the_western_exchange.py` - NumPy transpose
- `12-bracin_the_elements.py` - NumPy element-wise operations
- `13-cats_got_your_tongue.py` - NumPy concatenation
- `14-saddle_up.py` - NumPy matrix multiplication
